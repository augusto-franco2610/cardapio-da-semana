# Cardápio da Semana

Aplicativo web para planejar a alimentação semanal da família e gerar a lista de compras automaticamente.

**Acesse:** https://augusto-franco2610.github.io/cardapio-da-semana/

## Como funciona

- Monte cada dia da semana (café da manhã, almoço, lanche e jantar) com **receitas** ou **itens avulsos**.
- Informe quantas pessoas vão comer (padrão da família ou por refeição).
- A **lista de compras** soma todos os ingredientes da semana, ajustando cada receita pelo rendimento e cada item avulso pela quantidade por pessoa.
- Marque os itens no mercado e copie a lista formatada para o WhatsApp.

Os dados ficam salvos no navegador de cada pessoa (localStorage).
